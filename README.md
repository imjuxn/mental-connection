# Mental Connection

Mental Connection es una plataforma web para la gestión administrativa de turnos en servicios de salud mental.

El sistema permitirá administrar pacientes, profesionales, especialidades, disponibilidad horaria y turnos. Está pensado para profesionales de distintas áreas, como psicología, psiquiatría, psicopedagogía, fonoaudiología y disciplinas afines.
